### FR-001: Containerization: The platform must use a multi-stage Docker build with Python and Next.js dependency stages and a python:3.11-slim final runtime image.
Status: in_progress
Depends on: None

Description:
The platform must use a multi-stage Docker build with Python and Next.js dependency stages and a python:3.11-slim final runtime image.

Acceptance Criteria:
- [ ] Supervisor runs as PID 1.
- [ ] The Python LiveKit worker starts automatically.
- [ ] The dashboard is reachable on public container port 8000.
- [ ] The production dashboard uses Next.js standalone output and does not require npm start or a dev server.
